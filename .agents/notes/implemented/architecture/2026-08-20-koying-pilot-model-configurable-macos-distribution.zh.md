# Agent Note：柯影智航品牌化、可配置模型的 macOS 发行版

Status: implemented

[English](2026-08-20-koying-pilot-model-configurable-macos-distribution.md) | 中文

## 问题

首个原生桌面产物有意移除了全部模型路由与模型设置界面。正式产品发行版则需要让用户在安装后接入云端或本地提供方，具备独立产品身份，注明封装开发团队，致谢上游项目，并以常规 macOS 安装包交付，而不是只提供开发用 `.app`。

## 决策

产品命名为 **柯影智航**（Koying Pilot），并注明由柯影数智团队封装开发。原生壳、bundle identifier、可执行文件、Application Support 目录、菜单、应用文件名和窗口标题均使用该产品身份。封装过程把生成的图像资产编译成完整的 macOS `.icns` 尺寸集合。

`desktop` profile 保留 `dsh-base` 与 `dsh-web-app` 提供的模型适配器、模型选择器和模型设置页面。原生启动器不再在用户设置之后重复应用 desktop patch。提供方 profile 与托管凭据因此继续作为 `~/Library/Application Support/Koying Pilot` 下可写的应用本地状态；应用或安装包都不嵌入凭据，启动器仍清除继承环境中名称类似凭据的变量。

`@deepseek-ai/dsh-client-ui-about` 是仅由桌面版挂载的客户端插件。它向设置贡献本地化分节，展示产品身份、团队署名、致谢、版本和本地凭据说明。插件同时拥有桌面文档标题，并通过默认字标和符号上的语义化品牌挂钩替换共享侧边栏图案。替换仅在产品插件挂载时生效，因此其他 profile 仍保留共享图案。desktop 组合包只插入该插件，不修改面向模型的配置项。

封装器会验证 desktop 有效组装保持两个提供方适配器和两个模型配置 UI 项启用，在没有凭据时启动部署后的运行时，使用 ad-hoc 签名应用，并创建包含应用与“应用程序”快捷方式的压缩 DMG。

## 考虑过的替代方案

- **保持模型中立应用，再为提供方发布另一个版本**：普通模型接入会变成安装包选择，并重复桌面产品。
- **嵌入默认 API Key 或提供方凭据**：每份安装会共用同一秘密，检查产物即可恢复它。应用本地凭据存储让安装包可以复用，并使秘密按用户隔离。
- **只在原生 About 中放置致谢**：产品实际工作界面是 Web 设置；客户端插件能让署名显示在那里，并保持独立组装。
- **只发布 ZIP 或裸 `.app`**：两者都没有标准的拖入“应用程序”安装流程。DMG 无需特权安装脚本即可保留已签名应用包并提供该流程。

## 后果

- 全新安装可以从“模型”设置配置 DeepSeek、catalog 云提供方，或 Ollama 等声明式 OpenAI 兼容端点。
- 清除继承环境中名称类似凭据的变量，意味着 Finder 启动不会借用无关的 Shell 凭据；用户需要在应用中配置凭据。
- 生成的 DMG 可以在本机安装，但仍使用 ad-hoc 签名。公开分发需要 Developer ID 签名、hardened runtime 和公证。
- 产品文案与致谢是编译后的客户端资产，只会随重新构建的发行版改变。
- 共享品牌基础组件公开稳定的语义属性；产品 CSS 可以替换其呈现，而无需分叉侧边栏壳。
