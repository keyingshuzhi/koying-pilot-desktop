# dsh-client-ui-about

[English](README.md) | 中文

柯影智航的产品身份与致谢插件。桌面组合包把其页面挂载为设置中的末位分节，用于标明产品名称、注明柯影数智开发团队、致谢本发行版使用的上游与开源项目，并声明模型凭据在本机配置，而不会嵌入安装包。插件还会设置浏览器文档标题，并通过共享基础组件公开的语义化品牌挂钩，把共享侧边栏图案替换为柯影智航名称与字母标记。

该页面仅作静态展示，不读取 Host 数据、不提供操作；它只在设置壳声明 `settings.section` 后注册，卸载时同时移除页面和两套语言字典、恢复原文档标题并移除产品标记。

## 模型体验

无影响，因为该浏览器端致谢页面不添加模型上下文。

#### KV Cache 影响

无；该包不向模型请求添加任何内容。

## 已知限制与暂缓事项

- 产品版本与致谢名单是编译期文案；发行版修改其中任一内容后必须重新构建客户端包。
- 侧边栏身份使用文字与 CSS 呈现；原生应用图标仍来自打包后的 `.icns` 资源。
