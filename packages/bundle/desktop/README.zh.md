# `@deepseek-ai/dsh-desktop`

[English](README.md) | 中文

独立 macOS 应用“柯影智航”的产品层。它位于 `dsh-base` 与 `dsh-web-app` 之后，保留两者提供的模型适配器、模型选择器与模型设置页面，再插入柯影智航的“关于与致谢”页面。

提供方路由与凭据仍然是应用独立 Application Support 目录中的用户设置。该组合包不包含提供方凭据或内嵌 API 密钥；切换提供方无需重新构建应用。

## 模型体验

无影响，因为这个 patch-list carrier 只添加浏览器端产品信息页面。

#### KV Cache 影响

无；产品信息页面不向请求前缀添加任何内容。

## 已知限制与暂缓事项

- 桌面壳当前通过操作系统分配的 loopback 端口提供现有浏览器客户端；原生 IPC carrier 属于独立后续工作。
- 模型提供方仍需具备可访问的端点，并在适用时于“模型”设置中配置凭据。
